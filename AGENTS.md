# OpenRX

Family hub for the OpenRX boards: combined history, issues, releases and the production panel. Board sources live in OpenRX-Lite, OpenRX-Lite-UFL, OpenRX-Mono and OpenRX-Gemini.

Validate: `$KPY <hardware-tooling>/hardware/kicad/panel_merge.py panel/panel.json --check`

## Boundaries

- `panel/OpenRX-panel-rev2.2.*` is generated by `panel_merge.py` from `panel/panel.json`: never edit it by hand.
- Changes to nets, footprints or values go to the owning board repository: tag it, update the tag in `panel/panel.json`, rebuild.
- Do not recreate board sources in this repository.
